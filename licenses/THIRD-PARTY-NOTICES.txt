Rave Function: third-party software notices
===========================================

Rave Function's apps are built with the open-source software below. This
file and the licence texts it names are in the licenses/ folder inside every
app, and at https://ravefunction.com/download/ beside each download. The
credits for the music, the fonts, the avatar and the visual references are in
CREDITS.md, also inside every app.

Which apps carry what
---------------------
- Every app: Godot Engine with the libraries it includes (1), and the native
  core, which is this project's Rust code with godot-rust (2), Symphonia (3)
  and the other crates in rust-crates.txt (4). The Archivo font (7).
- The game (Quest, Vision Pro, phones, desktop): also IBM Plex Mono (7).
- Quest: also the OpenXR parts (5).
- Every Android app (the game on Quest, Rave Function Watch on Android
  phones): also AndroidX, Kotlin and LLVM's libc++ (6).
